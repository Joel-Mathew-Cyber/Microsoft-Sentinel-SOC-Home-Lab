
# Microsoft Sentinel SOC Home Lab

An Azure-based SOC home lab using Microsoft Sentinel to collect and analyze security logs, detect suspicious activity, and develop hands-on experience in threat detection and security monitoring.

**Project Status:** In Progress

## Objective

The objective of this project is to build a cloud-based Security Operations Center (SOC) home lab using Microsoft Azure and Microsoft Sentinel. This project focuses on collecting and analyzing security logs, monitoring suspicious activity, identifying potential threats, and gaining hands-on experience with SIEM tools, threat detection, and incident investigation in a simulated real-world environment.

## Skills Learned

- Configuring and managing virtual machines in Microsoft Azure.
- Understanding Security Information and Event Management (SIEM) concepts through Microsoft Sentinel.
